# Komponenter — kopierade från huvudappen

**Viktigt:** Dessa komponenter är kopierade från `src/components/` i huvudappen.
Två Next.js-appar har var sin React-instans och kan inte dela imports direkt (ADR 0013).

Ändringar i huvudappens komponenter måste **manuellt speglas här**.

Se ADR 0013 för fullständig förklaring.
