# Domänlogik — kopierad från huvudappen

**Viktigt:** Dessa filer är kopierade från `src/domain/` i huvudappen, inte importerade.
Två Next.js-appar har var sin React-instans och kan inte dela imports direkt (ADR 0013).

Ändringar i huvudappens domänlager måste **manuellt speglas här**.

Se ADR 0013 för fullständig förklaring varför vi kopierar i stället för att dela via npm workspace.
